# ToDo List Planner

Веб-приложение планировщик с возможностью добавления, просмотра, редактирования и отметки о выполении задач.

---

## Описание проекта

Приложение предоставляет собой серверную и клиентскую часть планировщика задач.

Сервер принимает и ьрабатывает HTTP-запросы, сохраняет данные в базу данных SQLite b реализует следующий функционал:

* Добавление новой задачи;

- Получение списка задач;
- Отметка задачи как выполненной;
- Редактирование задач;
- Повторяющиеся задачи (по правилам `d`, `w`, `m`, `y`);
- Аутентификация пользователей по паролю с использованием JWT-токенов;
- Обработка запросов через REST API.

## Что неоходимо для запуска:

1. **Запуск на сервере:**

1.1 Установка зависимостей:

```bash
go mod tidy
```

1.2 Настройка переменных окружения:

```
TODO_DBFILE=data/scheduler.db
TODO_PORT=7540
TODO_PASSWORD=12345
TODO_SECRET=my_super_secret_key

```

1.3 Запуск приложения:

```
go run main.go
```

После запуска в консоли появится сообщение:

```
Server TODO started at http://localhost:7540

```

**Использование:**

В браузере нужно переити по адресу: [http://localhost:7540/login.html]()

2. **Запуск в Docker контейнере:**

```
docker run -d -p 7540:7540 -e TODO_PASSWORD=12345 -e TODO_SECRET=my_super_secret_key -v $(pwd)/data:/app/data --name todo-planner todo-list-planner
```

**Использование:**

В браузере нужно переити по адресу: [http://localhost:7540/login.html]()
